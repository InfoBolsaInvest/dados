# InfoBolsa dados

Dados públicos de mercado (cotações e lista de ativos da B3) usados pelo app InfoBolsa Investimentos.
Atualizados a cada 15 minutos no pregão a partir da [brapi](https://brapi.dev).

- `cotacoes.json`: preço e variação do dia de cada ativo.
- `catalogo.json`: nome, tipo, segmento e se há logo.

Não há dados de usuários aqui.
